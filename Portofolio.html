Chat Bot

Réalisation d'un agent conversationnel

×

Chat Bot

Dans le cadre d'un projet de groupe de première année en BUT informatique. Nous avons réalisé un agent conversationnel pour répondre à des questions de culture Général. L'utilisateur peut interagir avec l'agent par le biais d'un terminal.

Il a la possibilité de poser une question. Si la réponse est mauvaise, l'utilisateur peut apprendre à l'agent la Bonne réponse. L'agent peut aussi répondre à plusieurs questions à la fois dans le contexte de la Première question.

Nous y avons intégré un système de synovie permettant à l'agent de comprendre une question avec des fautes de Syntaxe.

J'ai personnellement réalisé le système de reconnaissance des questions. Pour cela, nous avons un fichier avec des Question et des réponses prédéfinies. Grâce à cela, j'ai identifié la et les mots clés d'une question.

Nous avons utilisé une méthode d'indexage pour des raisons de performance. En raison de cela, nous avons rédigé un rapport sur la complexité algorithmique de notre agent pour regarder à quel point notre système de recherche par index était plus rapide en comparaison à une approche plus naïve.

Nous avons codé la totalité du projet en Java et nous avons utilisé GitHub pour collaborer et partager les fichiers.

Open Food Facts

Réalisation d'une analyse poussé sur le nutriscore avec une basse de donné

×

Open Food Facts

Dans le cadre d'un projet à deux de première année en BUT Informatique, nous avons réalisé une étude de données à partir de la base Open Food Facts, une base de données collaborative contenant des informations nutritionnelles sur des milliers de produits alimentaires.

L'objectif du projet était d'exploiter et d'analyser ces données afin de mieux comprendre les facteurs influençant le calcul du Nutri-Score et de fournir des informations pertinentes aux consommateurs. Nous avons travailé sur le sujet des sucreries vendu Etat unis.

La première partie du travail consistait à explorer, nettoyer et structurer les données. La base contenant de nombreuses erreurs, valeurs manquantes et informations inutiles, nous avons dû sélectionner les données pertinentes avant toute analyse. Nous avons utilisé des requêtes SQL pour extraire et filtré des informations utiles.

Une fois les données préparées, nous avons réalisé plusieurs analyses statistiques et créé des graphiques permettant de visualiser les tendances, les corrélations et les caractéristiques nutritionnelles des produits étudiés.

Les résultats ont été synthétisés dans un rapport rédigé, présentant notre méthodologie, les traitements effectués sur les données et les conclusions obtenues à partir des analyses réalisées.

Réalisation d'un site web pour une entreprise

×

CGI

Dans le cadre d'un projet de goupe de 4 personne, nous avons concuun site web institutionnel pour une entreprise du secteur numérique. L'objectif était de concevoir un site destiné à un public d'élèves de 3e en recherche de stage, afin d'informer et d'aider les jeunes élèves à trouvé leur stage dans l'entreprise.

Le projet contient plusieurs étapes. Tout d'abord, nous avons réalisé une phase de recolte d'information de l'entreprise afin de comprendre son activité.

Nous avons également réfléchi à la formulation des projet de transition numérique et écologique de l'entreprise, pour les élèves de jeunes ne connaissant pas le milieux.

Dans une seconde partie, nous avons conçu la maquette du site, puis développé le site web en respectant cette maquette. L'objectif était de proposer une interface reprenant la charte graphique de l'entreprise et contenant le necessaire pour conforter un jeune de troisième de postuler pour un stage.

j'ai codé la totalité du projet en HTML5, CSS3 et utilisé Git pour versionner et partager les fichiers.
